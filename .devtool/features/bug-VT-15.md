# bug-VT-15 Полное зависание (freeze) UI при нажатии «Раскрыть всё» на вкладке Бюджеты

При тестировании вкладки «Бюджеты» (Сценарий F8, F35) обнаружена критическая проблема производительности рендеринга больших объемов данных.

### Ожидаемое поведение (по test-VT-05)
Нажатие на кнопку «Раскрыть всё» (Expand All) должно плавно разворачивать дерево. Ожидается, что используется React.memo, виртуализация (windowing) или фрагментированный рендер, чтобы браузер не блокировался. 

### Фактическое поведение
При нажатии на «Раскрыть всё» приложение (главный поток браузера) "встает" (freeze) на продолжительное время, не реагируя на действия пользователя, после чего дерево наконец отрисовывается.
Это происходит по нескольким причинам:
1. **Синхронный рендер тысяч узлов:** React пытается синхронно отрендерить 5 уровней иерархии (тысячи компонентов `BudgetRow`) без виртуализации (например, `react-window` или `react-virtuoso`).
2. **N+1 проблема с HR-блоком (F27):** Раскрытие проектов автоматически маунтит блок «Человеческие ресурсы» (`DepartmentBlock`), который лениво грузит данные (`getProjectDepartmentBudgets`). Если раскрыть сразу 100 проектов, может запуститься 100 тяжелых запросов, каждый из которых тянет весь `v_cache_project_department_budget` (~3000 строк).

### Как воспроизвести
1. Открыть `/tasks` -> вкладка «Бюджеты».
2. Нажать «Загрузить всё» (загрузить большой объем данных).
3. Нажать кнопку «Раскрыть всё» в заголовке таблицы.
4. Интерфейс намертво зависнет на несколько секунд.
