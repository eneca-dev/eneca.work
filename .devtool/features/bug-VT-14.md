# bug-VT-14 Шторм Server Actions при загрузке вкладки «Бюджеты»

При тестировании вкладки «Бюджеты» (Сценарии S1 и S2) вновь обнаружено поведение с водопадом лишних серверных запросов, аналогичное багам `bug-VT-06` и `bug-VT-12`.

### Ожидаемое поведение (по test-VT-05, S1/S2)
При холодной загрузке должно параллельно отправляться всего 3 запроса (`getResourceGraphData`, `getBudgets`, `getSectionCalcBudgets`), которые кешируются на 2-3 минуты или до бесконечности. При возврате на вкладку повторных загрузок быть не должно.

### Фактическое поведение
После нажатия "Загрузить всё" или перехода по вкладкам, помимо загрузки самих данных, в сеть снова улетает пачка из ~15 одинаковых `POST /tasks` запросов.
Главный подозреваемый во всей этой истории — функция `reloadPermissions()`, которая вызывается внутри `useEffect` либо на корневом `TasksView`, либо (что хуже) внутри компонентов-строк. Это приводит к тому, что каждый рендер или маунт спамит сервер. На вкладке "Бюджеты" это усугубляется тем, что данных (`budgets`) очень много, и одновременный шторм экшенов вызывает заметные тормоза и задержки в UI ("долго грузится").

### Как воспроизвести
1. Открыть `/tasks` -> вкладка «Бюджеты».
2. Нажать «Загрузить всё».
3. Проверить вкладку Network (множественные POST-запросы).
