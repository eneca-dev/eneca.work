# bug-VT-10 Несоответствие цветовой индикации % загрузки (F19)

Обнаружено расхождение между ожидаемым поведением в тестовой документации и фактической реализацией отображения загрузки отделов.

### Ожидаемое поведение (по test-VT-03, F19)
- ≤ 90% — зелёный цвет
- ~90–100% — жёлтый цвет
- > 100% — красный цвет (перегруз)

### Фактическое поведение
- < 90% — жёлтый цвет (воспринимается как недозагруз)
- 90–100% — зелёный цвет (оптимальная загрузка)
- > 100% — красный цвет

Текущее поведение выглядит более логичным с точки зрения бизнес-процессов (недозагруз — предупреждение/желтый, полная загрузка — норма/зеленый). 

### Требуется решение
Необходимо либо обновить требования в чек-листе тестирования, если текущая реализация верна, либо поправить логику в компоненте индикатора, чтобы она соответствовала исходному ТЗ.

Связано с [test-VT-03](./test-VT-03.md) (Сценарий F19).
