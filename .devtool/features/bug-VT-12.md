# bug-VT-12 Шторм Server Actions при загрузке и возврате на вкладку «Разделы»

При тестировании вкладки «Разделы» (Сценарии S1 и S2) обнаружено поведение, полностью аналогичное багу `bug-VT-06` с вкладки «Отделы».

### Ожидаемое поведение (по test-VT-04, S1/S2)
При первой загрузке (S1) должны параллельно уйти запросы контекста, затем 1 раз `getSectionsHierarchy` и 1 раз запрос пользователей. При возврате с другой вкладки (S2) запросов к тяжелым данным вообще быть не должно (`staleTime: Infinity`).

### Фактическое поведение
Сразу после перехода на вкладку и загрузки данных в сеть выстреливает шквал из **19 одинаковых `POST /tasks` запросов** (Server Actions). 
Этот водопад игнорирует кеш (React Query) и повторяется при переключении вкладок. Вероятно, каждый отрендеренный компонент (каждая строка раздела или проекта) независимо вызывает `reloadPermissions` или какой-то другой экшен при монтировании, либо происходит циклический ре-рендер с инвалидацией.

### Как воспроизвести
1. Открыть `/tasks` и авторизоваться.
2. Переключиться на «Разделы» и нажать «Загрузить всё».
3. Переключиться на «Канбан» и вернуться назад.
4. В Network DevTools наблюдается спам из `POST /tasks`.
