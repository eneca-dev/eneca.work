# bug-DH-04 Фикс светлой темы: съезжающий заголовок, боковое меню, человеческие ресурсы (Бюджеты)

## Проблема
В **светлой теме** ломается вёрстка/стили в нескольких местах приложения. Нужно пройтись по основным направлениям и привести светлую тему в порядок.

## Основные направления фикса
1. **Съезжающий заголовок** — заголовок «съезжает» / смещается (выровнять позиционирование, проверить отступы и контейнер шапки).
2. **Боковое меню** — поправить отображение сайдбара в светлой теме (фон, границы, контраст, активные пункты, иконки).
3. **Человеческие ресурсы на вкладке «Бюджеты»** — блок «ЧЕЛОВЕЧЕСКИЕ РЕСУРСЫ» (раздел `AP/КР/ОВ/ВК/ЭС/...`) в светлой теме отображается некорректно, починить стили.

## Контекст
- Тема переключается через `next-themes`, primary-цвет `#1e7260`, CSS-переменные в `globals.css` (паттерн `ThemeProvider` + `ThemeSync`).
- Проверять каждое направление **в обеих темах**, чтобы фикс светлой не сломал тёмную.

## Definition of Done
- [ ] Заголовок не съезжает в светлой теме, выровнен корректно.
- [ ] Боковое меню выглядит корректно в светлой теме (контраст, границы, активные состояния).
- [ ] Блок «Человеческие ресурсы» на вкладке «Бюджеты» отображается корректно в светлой теме.
- [ ] Тёмная тема не пострадала (регресс-проверка).
