# bug-VT-08 Лишние сетевые запросы при UI-взаимодействиях (фильтрация и сворачивание)

При выполнении сценариев S4 (изменение фильтра) и S5 (раскрытие/сворачивание отделов) на вкладке «Отделы» зафиксированы лишние вызовы Server Actions.

### Ожидаемое поведение (test-VT-03)
- **S4 (Фильтрация):** Должен быть 1 дебаунс-запрос после ввода, а не на каждое нажатие.
- **S5 (Сворачивание/раскрытие):** Это чисто клиентское действие, должно быть **ровно 0 сетевых запросов**.

### Фактическое поведение
В ходе тестирования при вводе фильтра и кликах по сворачиванию/разворачиванию было зафиксировано 3 новых `POST http://localhost:3000/tasks` запроса (Server Actions). Это свидетельствует о том, что:
1. Либо у фильтра сломан дебаунс (запросы улетают на каждый чих).
2. Либо сворачивание/разворачивание компонента вызывает ре-рендер, который почему-то дёргает серверные функции (возможно из-за отсутствия мемоизации или неправильного `useEffect`).

### Как воспроизвести
1. Открыть `/tasks` -> «Отделы».
2. Очистить лог Network.
3. Ввести текст в фильтр (проверить количество запросов).
4. Очистить лог и свернуть/развернуть любой отдел (проверить наличие запросов).
