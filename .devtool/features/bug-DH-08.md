# bug-DH-08 Не работают прямые ссылки (deep-links) на вкладки

## Описание
Если перейти по прямой ссылке с параметром вкладки (например, `http://localhost:3000/tasks?tab=budgets`) или по легаси-ссылке (например, `?sectionId=123&highlight=true`), приложение не переходит напрямую в контент вкладки. Вместо этого пользователь застревает на экране пикера «Выберите вкладку».
Обновление страницы (F5) также не решает проблему — URL остаётся правильным, но контент не рендерится.

## Возможные причины
- Логика маршрутизации или чтения SearchParams в `TasksView` / `TabPicker` работает некорректно.
- Состояние активной вкладки не инициализируется должным образом из URL при первой загрузке (SSR / Hydration mismatch).
