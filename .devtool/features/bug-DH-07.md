# bug-DH-07 Повторный запрос (кэш-мисс) при клике по вкладке

## Описание
При наведении курсора на карточку вкладки в пикере `/tasks` срабатывает фоновый префетч (запрос уходит и выполняется). Однако при последующем клике на эту же карточку, вместо мгновенного использования данных из кэша (cache-hit), отправляется **повторный POST-запрос** за теми же данными.

## Возможные причины
- Рассинхрон ключей `prefetchQuery` (в `useTasksPrefetch`) и реального `useQuery` в компоненте вкладки. React Query не может сопоставить ключи и делает новый запрос.
- Игнорирование `staleTime` при монтировании компонента.

## Ссылки
- Найдено во время тестирования задачи: `test-DH-05` (Сценарий S4).

## Решение (2026-06-15)
Префетч по hover отключён (`TASKS_PREFETCH_ENABLED = false`,
`modules/tasks/components/TabPicker.tsx`). Раз нет hover-префетча — нет и кэш-мисса
«прогрели один ключ, читаем другой»: клик по карточке грузит данные при открытии
вкладки как обычно. Корневой рассинхрон ключей актуален только при включённом
префетче — выровнять ключи перед повторным включением.

## Переоткрыт (2026-06-15, после ручного теста)
Тестировщик: при наведении на карточку «Бюджеты» в Network всё ещё летят POST. Провёл
систематический дебаг кода:
- Карточки пикера — `<button>`, НЕ `<Link>` (роут-префетча Next нет); `onMouseEnter →
  handlePrefetch` гейтится `TASKS_PREFETCH_ENABLED=false` → no-op. Других путей префетча
  в `modules/tasks` нет.
- Дев-сервер (старт 19:11:21) НОВЕЕ коммита cddc963 (19:10:28) → тестилась исправленная сборка,
  не stale-код.
**Вывод:** hover НЕ префетчит. POST-ы на пикере — baseline, не префетч: `useTasksFilterOptions`
(4 запроса: org/project/tags/filterContext, вызывается в `TasksView` безусловно — и на пикере)
+ `reloadPermissions()` + глобальный `ReferencePrefetch` (~6). Летят на маунте/в idle и совпадают
по времени с наведением. Пересекается с DH-06.
**Надо подтвердить в браузере:** те же POST летят БЕЗ наведения мыши. Тогда «hover-префетч»
закрыт, а остаточный симптом — baseline (deferred filter-options/permissions на пикере).
