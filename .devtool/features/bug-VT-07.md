# bug-VT-07 Рефетч Server Actions при возврате на вкладку Отделы (отсутствие кеширования)

При переключении с вкладки «Отделы» на другую вкладку (например, «Канбан») и возврате обратно наблюдается повторная отправка Server Actions.

### Ожидаемое поведение (согласно test-VT-03, S2)
Данные отделов (`getDepartmentsData`) имеют настройку `staleTime: Infinity` и не должны перезапрашиваться при возврате на уже посещенную вкладку (должен быть кеш-хит).

### Фактическое поведение
В логах сети зафиксировано два новых `POST http://localhost:3000/tasks` запроса сразу после возврата на вкладку. Это означает, что компоненты заново триггерят Server Actions при монтировании (вероятно, `reloadPermissions` или рефетч `getDepartmentsData` без учета кеша).

### Как воспроизвести
1. На странице `/tasks` перейти на вкладку «Отделы».
2. Дождаться загрузки (см. баг `bug-VT-06`).
3. Переключиться на «Канбан» и сразу вернуться на «Отделы».
4. В Network появится минимум 2 новых POST-запроса к Server Actions.
