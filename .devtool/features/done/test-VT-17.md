# test-VT-17 Протокол замера DOM/freeze на /tasks: нужна ли виртуализация и где

Родительская задача: **bug-VT-02**. Питает решение по **[bug-VT-15](./bug-VT-15.md)** (freeze при раскрытии, отсутствие виртуализации). Тестируем по правилам «Человек + Нейросеть».

## Цель
Воспроизводимо измерить рендер-нагрузку вкладок «Отделы», «Разделы», «Бюджеты» (число DOM-узлов, freeze/long-task на раскрытие, rendered-vs-visible) и по чётким порогам дать вердикт: **нужна ли виртуализация и на какой вкладке**. Результаты — доказательная база для тикета на виртуализацию.

## Контекст
- Виртуализации в проекте нет нигде (проверено: ни `react-window`/`@tanstack/react-virtual`/`react-virtuoso`, ни windowing). SB-01 ускорил **данные** Бюджетов (лёгкая `v_budget_hierarchy` + ленивые этапы/задачи), но число DOM-узлов почти не трогал — это отдельная проблема рендера (VT-15).
- Предыдущий ручной замер (через Playwright, **до уточнения состояний**): Отделы ~1 569, Разделы ~26 310, Бюджеты ~37 706 узлов. Нужно перемерить **по состояниям и после мерджа SB-01**.
- Почему вкладки разные: «Отделы» по дефолту свёрнуты, тяжёлый контент (`EmployeeRow` = бары + ~300 ячеек дня) рендерится только на expand; «Бюджеты» авто-раскрывают все проекты на старте (`seedIfEmpty`, `BudgetsHierarchy.tsx:44-46`); «Разделы» — похоже + таймлайн-ячейки.

## Среда
- `localhost:3000`, dev-режим, тестировщик авторизуется сам (роль **админ** — максимальный веер).
- Браузер открывает ИИ через Playwright MCP; ИИ читает DOM/perf через `browser_evaluate`.
- БД — Supabase MCP (только чтение, при необходимости свериться с размером дерева).

## Решающее правило (вердикт «нужна / где»)
Виртуализация нужна для вкладки, если выполнено **хотя бы одно**:
- `S1 totalDom > 5 000`, или
- одно раскрытие (S2/S3) добавляет **> 2 000** узлов, или
- `maxBlockMs > 500` (при 4× CPU), или
- `rendered/visible > 8×`.

Иначе — **не нужна** (эталон — Отделы ~1.5k).
Доп. различение: большой `S1` при малом `S2 Δ` → дешевле лечится отказом от авто-раскрытия на старте (без виртуализации). Большой `S2 Δ` → нужна именно виртуализация.
