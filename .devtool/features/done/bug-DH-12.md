# bug-DH-12 Утечка сетевых запросов (нет AbortSignal) при уходе с пикера

## Описание
Если зайти на страницу `/tasks` и, не дожидаясь завершения фоновых префетчей, быстро уйти на другую страницу, запросы не отменяются (`canceled`). Они продолжают выполняться в фоне, "съедают" интернет-трафик и нагружают сервер, после чего возвращают `200 OK` в никуда.

## Ожидаемое поведение
При размонтировании страницы (уходе на другой маршрут) все выполняющиеся запросы (in-flight), относящиеся к этой странице, должны отменяться через `AbortSignal` (связанный с `QueryClient`).

## Ссылки
- Найдено во время тестирования задачи: `test-DH-05` (Сценарий S11).

## Решение (2026-06-15)
Префетч отключён (`TASKS_PREFETCH_ENABLED = false`): фоновых in-flight запросов на
пикере больше нет, отменять нечего — «хвоста» запросов после ухода со страницы не
возникает. Если префетч вернут — добавить отмену через AbortSignal /
`queryClient.cancelQueries` при размонтировании.
